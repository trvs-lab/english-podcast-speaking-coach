# 学习记录

仅在读取跨课状态、初始化或导入工作区、课末写回时读取。所有存储操作都服务于课堂连续性，不要向学习者展示内部读写过程，也不要延迟第一道口语题。

## 工作区发现

若学习者明确提供项目或课程目录，使用该目录下的 `english-coach/`。否则从当前目录向上查找最近的 `english-coach/PROFILE.md`；最多检查五层，遇到文件系统根目录或学习者主目录前停止。若没有 v2 工作区，再用相同范围查找 `english-coach/WORKSPACE.md`，只把它视为待非破坏导入的旧工作区。

没有任何工作区时，把当前项目下的 `english-coach/` 作为新工作区。不要要求学习者选择路径。第一次课程可以先开课，在需要课末记录时一次性建立最小结构；不要为了初始化增加一轮“继续”。

讨论、修改或评审本 skill 时，不发现、不创建也不写入学习者工作区。

## v2 文件结构

只维护四种职责：

```text
english-coach/
  PROFILE.md
  PHRASES.md
  REVIEW.md
  lessons/
```

- `PROFILE.md`：长期学习目标、场景偏好、大致能力、常用课文来源，以及 `schema_version: learning-centered-v2` 和一次性迁移标记。只记录会影响后续教学的稳定信息。
- `PHRASES.md`：只保存有无提示新情境证据的表达，状态只能是 `active` 或 `stable`。
- `REVIEW.md`：保存仍在学习的表达，以及反复出现的语法、搭配或拼写问题，状态只能是 `learning` 或 `repaired`。
- `lessons/*.md`：简短、可读的课次摘要，也是人工恢复最近一课的依据。

不要为了内部管理再创建编号体系、索引文件、事务记录、状态副本、休眠区或派生视图。

新建文件时使用最小可读结构。`PROFILE.md` 至少包含：

```markdown
# 学习者档案

- schema_version: learning-centered-v2
- 主要目标：<已知则填写；未知可留空>
- 场景偏好：<已知则填写；未知可留空>
- 大致能力：<只写有证据的判断>
- 常用来源：<系列或材料类型>
```

`PHRASES.md` 和 `REVIEW.md` 以表达本身开头，每项只保留中文用途、状态、最近证据和适合再次使用的场景。让人能直接阅读，不要写成数据库记录。

## 启动读取

普通跨课启动只读取：

```text
PROFILE.md
REVIEW.md
```

用 `PROFILE.md` 辅助推断学习目标，但当前请求始终优先。只从 `REVIEW.md` 选择与本课自然相容的少量项目；没有合适项目就正常学习新课，不要强塞复习。

仅在检查重复、选择间隔复习或课末写回时读取 `PHRASES.md`。仅在学习者明确要求回顾某一课，或当前状态存在明显冲突时读取旧 lesson 文件。不要在普通启动时扫描全部历史。

工作区读取和必要的新建在后台完成。第一条学习者可见消息仍应是实际口语提示，而不是文件检查报告。

## 表达状态

只使用四个易懂状态：

```text
第一次尝试或得到帮助 -> REVIEW: learning
得到帮助后成功修复 -> REVIEW: repaired
稍后在新情境中无提示说出 -> PHRASES: active
后续课程经过间隔再次无提示说出 -> PHRASES: stable
```

状态依据：

- 看过答案、跟读、照抄、句框补全和紧邻答案的复述，都不能进入 `PHRASES.md`。
- 原课文场景中的一次成功可以算本课覆盖，但要在不同的新情境中无提示说出，才记为 `active`。
- 尚未练习的核心或次要候选只写入 lesson 的“下一步”，不要加入 `REVIEW.md`。
- 同一个表达在当前课得到帮助后，先留在 `REVIEW.md`；后来达到 `active` 时从 `REVIEW.md` 移除并写入 `PHRASES.md`。
- 已在 `PHRASES.md` 的表达后来失败时，保留原有证据和状态，同时把它加入 `REVIEW.md`；再次无提示成功后再移出复习。不要引入更多中间状态。
- 学习者对自己的目标、掌握情况和历史记录所做的明确纠正优先于教练推断。

## 课末记录

每次完成或暂停的课程都使用以下简洁 lesson 文件：

```markdown
# <日期> <课题>

## 本课场景
<一段话>

## 已经能主动说
- `<表达>`：<中文用途>；证据：<新场景中的学习者句子>

## 下次继续练
- `<表达或问题>`：<简短原因和中文回忆提示>

## 词汇
- `<词>`：<中文义>

## 下一步
<剩余学习块或下次优先复习内容>
```

先写 lesson 文件，再更新 `PHRASES.md` 和 `REVIEW.md`。只有长期目标、稳定偏好、常用来源或有充分证据的能力估计发生变化时，才更新 `PROFILE.md`。不要在学习者可见的课末回复中讲解写入顺序。

记录时遵循以下边界：

- “已经能主动说”只收录无提示新情境证据；辅助完成的表达进入“下次继续练”。
- 未练习候选留在“下一步”，不伪造成失败记录。
- 只保留足以支持后续教学的学习者原句，不写逐轮聊天转录。
- 若课末文件写入成功而后续汇总文件更新失败，以 lesson 文件为人工恢复依据，并简短告知学习者记录未完全更新。

## 从 stateful-v1 非破坏导入

当 `english-coach/WORKSPACE.md` 存在而 `PROFILE.md` 不存在时，按以下方式导入：

1. 不要为了迁移延迟第一道口语题；先正常开课。
2. 只有确实需要跨课状态或课末写回时，才读取旧版 `MISSION.md`、`NOTES.md`、`state/CURRENT.md`、`state/review-queue.md` 与 `state/repair-bank.md` 的有效部分，以及相关的 `phrase-bank/*.md`。
3. 在课末于旧文件旁创建 v2 文件，不移动旧目录。
4. 把明确的长期目标和偏好写入 `PROFILE.md`，把有可靠 `active` 或 `stable` 证据的表达写入 `PHRASES.md`，把仍有效的复习与修复项写入 `REVIEW.md`。
5. 在 `PROFILE.md` 记录 `migrated_from: stateful-v1` 和迁移日期。
6. 不要删除、重命名或自动重写任何旧文件。
7. 后续发现 `schema_version: learning-centered-v2` 时优先读取 v2 文件，不再重复导入。

旧数据损坏、互相矛盾或证据不足时，保留原文件，只导入能明确判断的项目。把跳过的类别和原因写入当次 lesson 文件；不要为了恢复所有旧状态重新建立复杂的事务系统。

## 隐私

学习记录保存语言模式，不保存不必要的私人事实。默认把真实姓名、公司、地址、健康情况、家庭事件、关系、薪资、法律问题和敏感工作信息替换成 `a colleague`、`a client`、`a family event`、`a health issue` 或 `a company project` 等通用情境。

如果学习者明确要求某项内容不被记录，就完全不写入；语言模式仍有价值时，只保存去身份化的通用例句。学习者明确要求保留具体事实时，也只在完成当前教学所必需的范围内记录。

## 异常处理

- 文件不存在：创建最小模板并继续，不重建多余结构。
- 文件格式损坏：不要覆盖原文件；使用仍可读的明确内容，把异常和未导入项目记入当次 lesson。
- 状态冲突：优先采用学习者明确纠正，其次采用较新的无提示新情境证据；仍不确定时保留较保守状态并放入 `REVIEW.md`。
- 写入失败：保留已经成功写入的 lesson 作为恢复依据，停止继续改写相关文件，并向学习者简短说明哪一部分没有保存。
- 找到多个工作区：使用离当前项目最近或学习者明确指定的工作区；只有选择会改变真实学习历史时才问一个简短问题。
