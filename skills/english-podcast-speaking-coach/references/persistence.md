# 学习记录

首次建立工作区、读取跨课状态或课末写回时使用本文件。所有读写在课堂后台完成，不能阻塞第一条教学消息。

## 工作区发现

学习者明确提供项目或课程目录时，使用该目录下的 `english-coach/`。其他情况下，从当前目录向上查找最近的 `english-coach/PROFILE.md`，最多检查五层，并在文件系统根目录或学习者主目录停止。

找到现有工作区时直接复用。没有找到时，在当前项目下建立 `english-coach/`。找到多个工作区且选择会改变真实学习历史时，用一个简短问题确认。

## 文件结构

```text
english-coach/
  PROFILE.md
  PHRASES.md
  REVIEW.md
  lessons/
```

- `PROFILE.md`：长期学习目标、场景偏好、大致能力和常用材料来源。
- `PHRASES.md`：已经有无提示新情境证据的表达，状态为 `active` 或 `stable`。
- `REVIEW.md`：仍在学习的表达，以及反复出现的语法、搭配或拼写判断，状态为 `learning` 或 `repaired`。
- `lessons/*.md`：每课的场景、证据、词汇和下一步，是最近一课的恢复依据。

不为内部课程清单、候选列表或词汇分类新增长期文件。

新建 `PROFILE.md` 时使用：

```markdown
# 学习者档案

- 主要目标：<已知则填写>
- 场景偏好：<已知则填写>
- 大致能力：<只填写有证据的判断>
- 常用来源：<系列或材料类型>
```

`PHRASES.md` 和 `REVIEW.md` 以完整表达或问题模式作为条目标题，记录中文用途、状态、最近证据、证据课次，以及适合再次使用的场景。

同一交际功能只替换人物、事物、时间或数字时合并为一个条目，并追加代表性证据。交际目的、含义、语域或句法结构发生实质变化时再拆分。不把同一复合句的内部片段重复建成多个 active 条目。

## 启动读取

普通新课读取：

```text
PROFILE.md
REVIEW.md
```

用 `PROFILE.md` 辅助确定用途，但当前请求始终优先。从 `REVIEW.md` 中选择与本课自然相容的少量项目，其余留待更合适的课程。

检查重复、选择跨课复习或执行课末写回时读取 `PHRASES.md`。学习者明确回顾某一课或当前状态存在冲突时读取相关 lesson。第一条正式教学消息不被记录工作阻塞。

## 轻量跨课复习

新课通常穿插一个、最多两个自然相容的跨课项目，计入当前学习块的表达总量。优先级：

1. `repaired`：下一次课程优先做无提示提取；确实无法自然进入本课场景时，在 lesson 的“下一步”中说明留待原因；
2. `learning`：当前场景能组成一步可完成任务时再练；
3. `active`：距离最近证据已经完成至少两次其他课程后检查；
4. `stable`：任务自然需要或学习者主动复习时使用。

到达间隔只影响选择优先级，不自动改变状态。纯复习课从 `REVIEW.md` 和 `PHRASES.md` 总计选择 1–3 个能组成同一场景的项目。

## 证据与状态

```text
原场景无提示主动尝试成功 -> lesson: covered
关键词、短框架、完整示范或明确提醒后完成 -> REVIEW: repaired
核心表达尚未获得独立迁移 -> REVIEW: learning
无提示、有意义变化的新情境成功 -> PHRASES: active
active 后在后续课程再次无提示成功 -> PHRASES: stable
```

状态边界：

- 原课文场景中的一次正确回答记录在 lesson，但不直接支持 `active`。
- 只替换人物、名词、时间或数字的同构练习保持原状态。
- 题面显示关键块、答案刚揭示、关键词、句框、填空或明确提醒后的成功最高为 `repaired`。“刚揭示”“刚提醒”指该成功与揭示或提醒之间隔着少于三次其他有效开口，或题面仍显示该英文。
- 素材没有可复用的叙事场景（预告片、独白集锦等）时，每道题都按新情境判定：无提示首答成功直接支持 `active`，不适用原场景覆盖条款。
- 新情境至少改变关系、约束、信息结构、交际目的、语气压力或后续动作中的一项，并要求学习者重新选择或组织语言。
- 第一次合格的无提示新情境表达支持 `active`；只有后续课程的再次间隔成功支持 `stable`。
- `repaired` 后在无提示新情境成功时移入 `PHRASES.md` 并更新为 `active`。
- 只轻练过一次的次要表达保存在 lesson，不必进入 `REVIEW.md`。
- 学习者对目标和掌握情况的明确说明拥有最高证据优先级。

`PHRASES.md` 中的表达后来出现困难时保留已有历史，同时在 `REVIEW.md` 加入当前问题。再次独立成功后完成复习，不删除过去的有效证据。

问题模式首次定位时进入 `REVIEW.md: learning`，专项修复后记为 `repaired`。后续相关场景验证成功时从 `REVIEW.md` 移除，并把修复证据留在 lesson；再次出现时重新加入。

## 课末写回

每次完成或暂停后，先写 lesson，再更新 `PHRASES.md` 和 `REVIEW.md`：

```markdown
# <日期> <课题>

## 本课场景
<一段话>

## 已经能自己说出来
- `<表达>`：<中文用途>；回忆提示：<具体中文场景>；证据：<新情境中的学习者原句>

## 本课已经覆盖
- `<表达>`：<中文用途>；证据：<原场景主动尝试或对比选择>

## 还要再练一下
- `<表达或问题>`：<需要继续的原因>；回忆提示：<具体中文场景>

## 这节课碰到的词
- `<词>`：<中文义>

## 下一步
<中途结束时记录剩余内容；完整结束时记录下一次优先复习>
```

没有条目的区省略。

写回边界：

- “已经能自己说出来”只收录无提示、有意义变化的新情境证据。
- “本课已经覆盖”收录只有原场景主动尝试证据的表达，不进入 `PHRASES.md`。
- 得到帮助、等待延迟提取或出现反复问题的表达进入“还要再练一下”。
- 未练内容只有在暂停或负担信号中断课程时进入“下一步”，不写成学习者困难。
- 自然替代作为同一表达的代表性证据保存，不为每个替代建立重复条目。
- 学习者原句只保留支持后续教学所需的最小片段。
- 长期目标、稳定偏好或有充分证据的能力估计发生变化时才更新 `PROFILE.md`。

lesson 写入成功而汇总文件更新失败时，以 lesson 作为恢复依据，并简短说明保存结果。

## 隐私

学习记录只保存教学需要的语言模式和证据。涉及真实姓名、公司、地址、健康、家庭、关系、薪资或法律信息时，默认改写为 `a colleague`、`a client`、`a family event`、`a health issue` 或 `a company project` 等通用情境。

学习者明确选择保留或省略某项事实时，以其当前说明为准。

## 异常处理

- 文件缺失：创建最小模板并继续。
- 文件格式损坏：保留原文件，使用仍可读取的内容，并在 lesson 记录异常。
- 状态冲突：优先采用学习者明确说明，其次采用较新的高质量证据；其他情况使用较保守状态并加入 `REVIEW.md`。
- 写入失败：保留已经成功写入的 lesson，停止后续文件更新并简短说明结果。
- 网络中断、流式错误或误发：不据此改变学习状态；恢复后让学习者补完当前表达。
