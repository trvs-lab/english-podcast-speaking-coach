# 学习记录

在读取跨课状态、首次建立工作区或课末写回时使用本文件。所有读写都在课堂后台完成，让学习者先进入第一道口语题。

## 工作区发现

学习者明确提供项目或课程目录时，使用该目录下的 `english-coach/`。其他情况下，从当前目录向上查找最近的 `english-coach/PROFILE.md`，最多检查五层，并在到达文件系统根目录或学习者主目录时停止。

找到现有工作区时直接复用。没有找到时，在当前项目下建立 `english-coach/`。工作区发现只在真实教学会话中执行。

## 文件结构

```text
english-coach/
  PROFILE.md
  PHRASES.md
  REVIEW.md
  lessons/
```

- `PROFILE.md`：保存长期学习目标、场景偏好、大致能力和常用课文来源。
- `PHRASES.md`：保存有独立新情境证据的表达，状态为 `active` 或 `stable`。
- `REVIEW.md`：保存仍在学习的表达，以及反复出现的语法、搭配或拼写问题，状态为 `learning` 或 `repaired`。
- `lessons/*.md`：保存简短、可读的课次摘要，并作为最近一课的恢复依据。

新建 `PROFILE.md` 时使用以下最小结构：

```markdown
# 学习者档案

- 主要目标：<已知则填写>
- 场景偏好：<已知则填写>
- 大致能力：<填写有证据的判断>
- 常用来源：<系列或材料类型>
```

`PHRASES.md` 和 `REVIEW.md` 直接以表达或问题作为条目标题，每项记录中文用途、状态、最近证据和适合再次使用的场景。四个位置共同构成完整的学习记录。

## 启动读取

普通跨课启动读取：

```text
PROFILE.md
REVIEW.md
```

用 `PROFILE.md` 辅助确定学习目标，同时让当前请求保持最高优先级。从 `REVIEW.md` 中选择与本课自然相容的少量项目；其余项目留待更合适的课程。

检查表达重复、选择间隔复习或执行课末写回时读取 `PHRASES.md`。学习者明确回顾某一课或当前状态存在明显冲突时读取相关 lesson 文件。第一条学习者可见消息仍采用真实口语题的课堂形状。

## 表达状态

```text
第一次尝试或得到帮助 -> REVIEW: learning
得到帮助后成功修复 -> REVIEW: repaired
稍后在新情境中无提示说出 -> PHRASES: active
后续课程经过间隔再次无提示说出 -> PHRASES: stable
```

状态依据：

- 新情境中的无提示表达支持 `active`；后续课程中的间隔成功支持 `stable`。
- 原课文场景中的成功支持本课覆盖，并等待新情境证据确认 `active`。
- 答案展示、跟读、照抄、句框补全和紧邻答案的复述进入 `REVIEW.md`。
- 尚未练习的核心或次要候选写入 lesson 的“下一步”。
- 表达达到 `active` 时，从 `REVIEW.md` 移入 `PHRASES.md`。
- `PHRASES.md` 中的表达后来出现困难时，保留已有证据，同时把当前问题加入 `REVIEW.md`；再次独立成功后完成复习。
- 学习者对目标、掌握情况和历史记录的明确说明拥有最高证据优先级。

## 课末记录

每次完成或暂停的课程都使用以下 lesson 文件：

```markdown
# <日期> <课题>

## 本课场景
<一段话>

## 已经能主动说
- `<表达>`：<中文用途>；证据：<新场景中的学习者句子>

## 下次继续练
- `<表达或问题>`：<简短原因和中文回忆提示>

## 词汇
- `<词>`：<中文义>

## 下一步
<剩余学习块或下次优先复习内容>
```

先写 lesson 文件，再更新 `PHRASES.md` 和 `REVIEW.md`。长期目标、稳定偏好、常用来源或有充分证据的能力估计发生变化时，再更新 `PROFILE.md`。

记录边界：

- “已经能主动说”收录无提示新情境证据。
- 辅助完成的表达进入“下次继续练”。
- 尚未练习的候选进入“下一步”。
- 学习者原句只保留支持后续教学所需的最小片段。
- lesson 写入成功而汇总文件更新失败时，以 lesson 作为恢复依据，并简短说明保存状态。

## 隐私

学习记录保存语言模式和教学证据。涉及真实姓名、公司、地址、健康情况、家庭事件、关系、薪资、法律问题或敏感工作信息时，使用 `a colleague`、`a client`、`a family event`、`a health issue` 或 `a company project` 等通用情境。

学习者的记录偏好具有最高优先级。学习者选择省略某项事实时，只保存去身份化的语言模式；选择保留具体事实时，以当前教学真正需要的信息为范围。

## 异常处理

- 文件缺失：创建最小模板并继续。
- 文件格式损坏：保留原文件，使用仍可读取的明确内容，并把异常记入当次 lesson。
- 状态冲突：优先采用学习者明确说明，其次采用较新的无提示新情境证据；其他情况使用较保守状态并加入 `REVIEW.md`。
- 写入失败：保留已经成功写入的 lesson，结束相关文件更新，并向学习者简短说明保存结果。
- 找到多个工作区：使用离当前项目最近或学习者明确指定的位置；选择会改变真实学习历史时，用一个简短问题确认。
